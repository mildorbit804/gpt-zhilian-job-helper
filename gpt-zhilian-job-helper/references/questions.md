# 问答方式（助手执行，不念给使用者）

只问确实缺少且影响当前步骤的信息；已有明确回答沿用。说明、功能介绍、核查结果不做成选择题。先判断题意是单选、多选还是自由文字，再选当前宿主实际提供的工具。

## 弹窗与降级

- 能点选的优先用宿主问答弹窗，题目里写“单选”或“可多选”。真正支持多选时才使用多选控件。
- 当前 Codex 的 `request_user_input_async` 选项每题只选一个，且支持自由输入：单选用 `options`；多选不要传成单选选项，应省略 `options`，在题目列固定编号并写“可多选，请填写编号，例如 1、3”。学历、日期、到岗时间也省略 `options`，直接让用户填写。
- 其他宿主使用其实际可用工具；只支持单选时，多选题也改用编号加自由输入。没有可用弹窗就在聊天中按同样方式问，不安装工具、不切换模式来追求弹窗。
- 不受工具支持的选项数量不能截断或漏掉；可改用完整编号列表加自由输入。工具自带自由填写入口时，不另加重复的“其他”选项。
- 互斥项不能同时成立：“都没有”“全部不用”不能和具体项目一起选。回答冲突时只补问冲突处；不能自行挑一个当答案。
- 预选、未回复、超时都不算回答。异步提问后可继续不依赖答案的已授权工作；收到回答后再做依赖步骤，不重复追问同一题。
- 单选如必须有首项，优先用中性的“不采用／暂不补充”等适合题意的选项；不为就业状态等事实问题推荐答案，也不因控件默认预选保存选择。

## 各处题型

| 场景 | 题型与用法 |
|---|---|
| 网页没有的补充要求 | 可多选：作息、加班、通勤、具体职责；也可直接填要求或说“没有”。选择类别后，只补问还没说清的具体要求，不能把“作息”自动理解为必须双休 |
| 本轮发布时间范围 | 单选：最近 7 天、最近 14 天、一直翻到底；支持自由填写其他天数，已有约定不重问 |
| 背景提供方式 | 单选三项：1. 回答几个问题；2. 上传简历或片段；3. 授权读取智联在线简历。明确选第 3 项后才正常打开只读，不因预选或添加选项就读取。选第 2 项后的附件请求在普通聊天中说明，不用仅支持文字的工具索要附件 |
| 当前就业状态 | 单选，沿用招呼语文档的五个明确类别；允许直接说明，不替用户判断 |
| 学历、到岗时间、具体经历、阈值 | 自由文字，不给学历选项，不默认随时到岗或用建议阈值填空 |
| 做过的事情 | 可多选，给与方向有关的具体任务，保留“都没做过”且与其他项互斥；选任务不等于已提供成果，需要时再问一句实例 |
| 是否参考核查经验 | 单选：全部不用、全部采用表中建议、挑选或修改；先展示完整经验清单及边界，最后才问，不暗中采用 |
| 条件差距处理 | 在经验询问最后、确有需要且尚未约定时单选：逐项列出由用户决定、达到指定数量提醒、达到指定数量排除；后两项再自由填写数量及计数范围。无默认阈值，不随整包采用 |
| 具体经验项目 | 可多选，保留原来的 1—8 编号，允许编号加“改成只提醒”等文字；“全部不用”与选择项目互斥 |
| 标题屏蔽词 | 可多选，先列标签、词、命中数量和误排影响；回复编号可选择多项，也能改词或全不采用 |

模拟问答只记进模拟目录；不能把角色学历、就业状态或选择写进真实求职记录或共享技能。没有当前网页证据的模拟不说“我刚看了页面”。
